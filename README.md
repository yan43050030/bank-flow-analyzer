# 银行流水资金统计工具

纯本地运行的银行流水分析软件，零联网、数据不外泄。专门用于从银行流水中统计资金数额，自动处理重复购买理财和反复取现存现的情况。

## 功能特性

- **导入银行流水**：支持 Excel(.xlsx/.xls)、CSV 格式
- **自动字段识别**：自动识别日期、姓名、卡号、交易类型、金额等字段
- **理财产品去重**：同一账户在设定时间窗口内、金额相近的理财交易自动合并，避免重复计算
- **取现/存现配对**：同一账户的取款和存款记录自动配对，按最小金额统计，避免资金来回倒腾的重复计算
- **按账户汇总**：每个账户的理财金额、现金配对金额、未配对取/存款、其他金额分别统计
- **结果导出**：导出为 Excel（含明细表、汇总表、统计摘要）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行方式

```bash
python fund_analyzer.py
```

## 使用说明

1. 点击「导入银行流水」，选择银行流水 Excel/CSV 文件
2. 系统自动识别字段，如有误可手动在下拉框中选择正确的列
3. 在「统计设置」中调整参数（默认通常即可）
4. 点击「开始统计」
5. 在右侧查看统计摘要、明细和汇总结果
6. 点击「导出统计结果」保存为 Excel

## 统计规则说明

### 理财产品去重

- **触发条件**：交易类型包含「理财」字样
- **去重逻辑**：同一卡号/账户，在设定天数内（默认30天），金额差异在设定容差内（默认±5%）的理财交易，视为同一笔资金的重复购买，合并为一条，取金额最大的一条
- **目的**：避免同一笔资金在不同理财产品之间轮动导致的重复计算

### 取现/存现配对

- **触发条件**：交易类型包含「取/提款/取款/取现/ATM取款」或「存/存款/存现/现金存入/ATM存款」
- **配对逻辑**：同一卡号/账户，取款后在设定天数内（默认14天）有金额相近（默认±20%）的存款，视为反复操作
- **统计规则**：配对成功后，按 `min(取款金额, 存款金额)` 计入统计金额
- **目的**：避免资金取出后又存回导致的重复统计

### 其他交易

- 未被上述规则匹配的转账、工资、消费等交易，按原金额正常统计

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 理财金额容差 | ±5% | 判定为重复购买的金额差异范围 |
| 理财时间窗口 | 30天 | 判定为重复购买的时间范围 |
| 现金金额容差 | ±20% | 判定为配对存取的金额差异范围 |
| 现金时间窗口 | 14天 | 判定为配对存取的时间范围 |
| 最小配对金额 | 1000元 | 低于此金额不参与配对 |
